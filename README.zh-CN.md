# 王钰钦 / Yuqin Wang

独立产品创作者，做一些与日常生活有关的小产品，也做帮助自己使用 AI 的工具。

我把具体的问题做成能运行的东西：怎样重新观察熟悉的城市，怎样从生活照片中发现知识，怎样让 AI 长任务在中断之后继续。
